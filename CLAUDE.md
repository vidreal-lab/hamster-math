# Хомяк учит умножение

Образовательная игра для детей младшего школьного возраста для изучения таблицы умножения.

## Описание проекта

Интерактивная браузерная игра, где хомяк помогает ребёнку учить таблицу умножения. Игрок выбирает хомяка, фон леса и число для изучения, затем тренируется решать примеры, выбирая правильный ответ среди вариантов на семечках подсолнуха.

## Архитектура

### Структура экранов

Игра состоит из 4 последовательных экранов:

1. **screen-hamster** — выбор персонажа (Рыжик, Дымок, Снежок)
2. **screen-forest** — выбор фона (Солнечный день, Закат, Туманное утро)
3. **screen-settings** — настройки игры (выбор числа 2-9 или "Вперемешку")
4. **screen-game** — игровой экран с примерами

### Модули (js/)

#### state.js
Управление состоянием через `localStorage`:
- Сохраняет выборы пользователя (хомяк, лес, число, режим)
- Хранит список ошибок для режима "Работа над ошибками"
- API: `get(key)`, `set(key, value)`, `getAll()`, `addMistake()`, `removeMistake()`, `clearMistakes()`, `getMistakes()`, `hasMistakes()`

#### screens.js
Навигация между экранами и обработка выборов:
- Управляет видимостью экранов
- Обрабатывает клики на кнопки выбора (`data-choice-group`, `data-value`)
- Синхронизирует UI с состоянием
- Управляет кнопками навигации (Назад/Дальше)
- Инициализирует режим "practice" и семечку "black" по умолчанию

#### math.js
Генерация математических примеров:
- `nextExample(number)` — генерирует пример умножения
- Поддерживает конкретное число (2-9) или случайное ("random")
- `generateDistractors(correct, count)` — генерирует неправильные варианты ответов

#### hamster.js
Отрисовка SVG-хомяка:
- Три варианта окраса: rusty (рыжий), grey (серый), white (белый)
- Три состояния: calm (спокойный), happy (радостный), sad (грустный)
- `drawHamster(svg, type, mood)` — рисует хомяка в указанном контейнере

#### forest.js
Отрисовка SVG-фона леса:
- Три варианта: sunny (солнечный), sunset (закат), foggy (туманное утро)
- Рисует небо, деревья, траву с различными палитрами
- `drawScene(svg, type)` — рисует полную сцену леса

#### leaf.js
Отрисовка семечек подсолнуха (контейнеры для вариантов ответа):
- Форма: вытянутая капля, перевёрнутая (острый конец вниз)
- Однотонная чёрная семечка (#1a1a1a)
- Поддержка подсветки: зелёная (correct) или красная (wrong)
- `createLeafElement(type, text, highlight)` — создаёт SVG-элемент семечки с текстом

#### sound.js
Звуковые эффекты:
- `playHappy()` — звук при правильном ответе
- `playSad()` — звук при неправильном ответе
- Использует Web Audio API с синтезированными звуками

#### game.js
Основная игровая логика:
- Управляет двумя режимами игры:
  - **practice** — основной режим тренировки
  - **mistake-review** — режим работы над ошибками
- Размещает семечки с вариантами ответов на сцене
- Обрабатывает клики по семечкам
- Обновляет счётчики (правильных ответов или оставшихся ошибок)
- Управляет переходами между примерами с задержками

### Режимы игры

#### Practice (Тренировка)
- Генерирует случайные примеры по выбранному числу
- Показывает 4 варианта ответа на семечках
- Ведёт счёт правильных ответов (отображается вверху)
- Сохраняет ошибки в localStorage
- При неправильном ответе:
  - Подсвечивает выбранную семечку красным
  - Подсвечивает правильный ответ зелёным
  - Увеличивает задержку до следующего примера до 2.1 секунды (вместо 1.1)
- Показывает кнопку "Работа над ошибками" если есть ошибки

#### Mistake-Review (Работа над ошибками)
- Показывает только те примеры, в которых были ошибки
- Ведёт счётчик оставшихся ошибок (отображается вверху)
- При правильном ответе удаляет пример из списка ошибок и обновляет счётчик
- При неправильном ответе:
  - Подсвечивает выбранную семечку красным
  - Подсвечивает правильный ответ зелёным
  - Увеличивает задержку до 2.1 секунды
  - Оставляет пример в списке для повторной попытки
- После исправления всех ошибок автоматически возвращается в режим practice

### Визуальная обратная связь

- **Правильный ответ**: семечка подсвечивается зелёным, хомяк радуется, счёт увеличивается
- **Неправильный ответ**: выбранная семечка красная, правильная зелёная, хомяк грустит, задержка 2.1 сек
- **Подсветка**: зелёная рамка для правильного, красная для неправильного ответа

## Технологии

- Vanilla JavaScript (ES6+)
- SVG для всей графики (хомяк, лес, семечки)
- localStorage для сохранения состояния
- Web Audio API для звуков
- CSS Grid/Flexbox для раскладки

## Важные детали реализации

### Тайминги и задержки
- **Правильный ответ**: 1100ms до следующего примера
- **Неправильный ответ**: 2100ms до следующего примера (даёт время запомнить правильный ответ)
- **Завершение mistake-review**: 800ms перед переходом в practice

### Расположение семечек
Семечки с вариантами ответов размещаются на 4 фиксированных позициях:
- Позиция 0: (300, 240) — левая верхняя
- Позиция 1: (600, 140) — правая верхняя
- Позиция 2: (250, 440) — левая нижняя
- Позиция 3: (550, 380) — правая нижняя

### Состояние игры
Ключи в localStorage:
- `hamster` — тип хомяка (rusty/grey/white)
- `forest` — тип леса (sunny/sunset/foggy)
- `leaf` — тип семечки (всегда "black")
- `number` — изучаемое число (2-9 или "random")
- `mode` — текущий режим (всегда "practice", меняется на "mistake-review" при нажатии кнопки)
- `mistakes` — массив объектов `{a, b, answer}` с ошибками
