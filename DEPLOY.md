# Как загрузить игру на Netlify

## Способ 1: Ручная загрузка через браузер (рекомендуется)

1. Откройте https://app.netlify.com в браузере
2. Войдите в аккаунт (или зарегистрируйтесь бесплатно)
3. Нажмите **"Add new site"** → **"Deploy manually"**
4. Перетащите всю папку проекта в окно браузера

Netlify загрузит все файлы и даст вам ссылку вида `https://ваш-проект.netlify.app`

## Способ 2: Через Netlify CLI

```bash
# Установите Netlify CLI (требуется Node.js)
npm install -g netlify-cli

# Перейдите в папку проекта
cd "C:\Users\vidre\OneDrive\Desktop\AI\игра хомяк"

# Залогиньтесь в Netlify
netlify login

# Задеплойте проект
netlify deploy --prod
```
